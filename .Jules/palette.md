## 2026-04-26 - ARIA labels for icon-only buttons
**Learning:** Icon-only buttons without `aria-label` attributes are a common accessibility anti-pattern in the codebase, particularly in complex UI components like document viewers where visual space is constrained.
**Action:** Always verify that buttons lacking descriptive text content include an appropriate `aria-label` to ensure screen reader users can interact with the controls.
## 2026-06-01 - Dynamic ARIA Labels in Tables\n**Learning:** When adding ARIA labels to repeating elements in data tables (like Action buttons), using static labels creates an ambiguous experience for screen reader users as they encounter multiple identical labels (e.g., "View Item" repeated 50 times).\n**Action:** Use dynamic template literals to inject row-specific identifiers (e.g., `row.original.part_number`) into the `aria-label` to provide crucial context and distinguish identical controls.
