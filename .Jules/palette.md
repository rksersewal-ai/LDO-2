## 2024-05-14 - Keyboard Support for Hidden Action Buttons
**Learning:** Found multiple instances where secondary action buttons (like "More options" icons) were hidden using `opacity-0 group-hover:opacity-100`. While this cleans up the visual UI, it completely hides these interactive elements from keyboard-only users who cannot trigger the `group-hover` state, as the elements never become visible on focus. Additionally, interactive UI elements (like the user profile toggle) were implemented using `div`s instead of semantic `button`s.
**Action:** When hiding interactive elements visually to reduce clutter, always pair `opacity-0 group-hover:opacity-100` with `focus-visible:opacity-100` and explicit `focus-visible:ring-2` styles so the element appears and indicates focus when tabbed to. Also ensure that all interactive components use native semantic tags like `<button>` and include context-aware `aria-label`s.
